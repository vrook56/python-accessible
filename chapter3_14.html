Chapter 3.14: Decimal Tip

What you are learning

Import Decimal, create bill_amount = Decimal('69.40') and tip_percentage = Decimal('0.15'), calculate the tip and total_bill, then print only total_bill formatted to two decimal places.

Example

from decimal import Decimal price = Decimal('10.00') rate = Decimal('0.20') total = price + price * rate print(f'{total:.2f}')
