Chapter 3.9: Product with Augmented Assignment

What you are learning

Use a for statement and multiplication augmented assignment to calculate the product of all non-zero values in [0, 5, 2, 3, 0, 1, 4]. Store the result in product.

Example

product = 1 for value in [2, 3, 4]: if value != 0: product *= value
