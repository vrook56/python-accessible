Chapter 3.11: Sentinel-Controlled Average

What you are learning

Use a sentinel-controlled while loop. Input positive integers until -1 is entered. Then calculate the average and store it in average. Use input() with no prompt.

Example

total = 0 counter = 0 value = int(input()) while value != -1: total += value counter += 1 value = int(input()) average = total / counter
