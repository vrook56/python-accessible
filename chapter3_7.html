Chapter 3.7: First Square Over 1000

What you are learning

Use a while loop to determine the first positive integer whose square is greater than 1000. number and square both begin at 0. Increase number by 1 each loop, and store number squared in square.

Example

number = 0 square = 0 while square <= 25: number += 1 square = number ** 2
