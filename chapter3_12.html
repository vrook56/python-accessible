Chapter 3.12: Multiples of Three

What you are learning

Use a for statement to input three integers. For each integer, use if...else to print whether it is a multiple of 3. Use input() with no prompt.

Example

for _ in range(2): n = int(input()) if n % 2 == 0: print(n, 'is even') else: print(n, 'is odd')
